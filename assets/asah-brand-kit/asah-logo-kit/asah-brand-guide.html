Asah brand guide

Asah is Malay for sharpen. The mark is a blade edge seen from the tip: a thick spine on the left, honed to a hairline cutting edge on the right. Skills, like knives, stay sharp through regular practice.

Version 1.0, September 2026. Thriving Talents Learning Platform, powered by frntlne.

Primary logo

The horizontal lockup is the default. Use it wherever width allows: website header, proposal covers, email signatures, booth backdrops. Use the stacked version when the space is square or narrow: social avatars, app splash screens, name badges.

Mark and wordmark

The mark works alone once the brand is known: favicon, app icon, loading state, the badge a learner earns when a course is complete. The wordmark works alone in running text or where the mark would be too small to read.

Colour

Three colours. Graphite is steel. Spark is what flies off the whetstone. Stone is the whetstone itself, used for secondary text. This palette is deliberately warm so Asah reads as a partner to frntlne's navy rather than a sub-brand of it.

Rules

Spark is for the mark and for one accent per screen. Never set body text in Spark. Never put Spark text on Graphite or Graphite text on Spark at small sizes, the contrast is not enough.

On backgrounds

On light backgrounds use the Graphite wordmark. On dark backgrounds use the white wordmark. The Spark mark stays the same on both. When colour is unavailable (fax, engraving, single-colour print) use the mono versions.

Powered by frntlne

The tagline lockup is for external-facing surfaces where the platform provider must be credited: the landing page, proposal covers, the login screen, the HRDC listing. Internal decks and the in-app UI can use the logo without the tagline. Confirm the exact wording and placement rules in the frntlne reseller agreement before printing.

Clearspace and minimum size

Keep a clear zone of x on all sides, where x is half the height of the mark. Nothing else enters this zone: no text, no other logos, no edges of the page. The SVG files already include this padding, so placing them edge to edge with other elements is fine.

Minimum size


Horizontal: 120 px wide, 28 mm print

Stacked: 72 px wide, 18 mm print

Mark: 16 px

Below these sizes, drop the tagline first, then drop the wordmark and use the mark alone.

App icon and favicon

Two app icon tiles are provided. The Graphite tile with the Spark mark is the default. The Spark tile with a white mark is for marketing surfaces where the icon needs to shout. The favicon uses a slightly heavier cutting edge so the shape survives at 16 px.

Typeface

The wordmark is set in Plus Jakarta Sans Bold, an open source typeface designed in Jakarta. Use the same family for the product UI and marketing so the brand feels consistent: Bold for headings, Medium for buttons and labels, Regular for body text.
